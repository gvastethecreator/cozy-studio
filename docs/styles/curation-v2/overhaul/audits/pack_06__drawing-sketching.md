# pack_06 :: 2. Drawing & Sketching — audit

Audited 2026-09-25 from the contact sheet (15 primaries) and full manifests. Category kind `style`; the review rule is "graphite, charcoal and pen remain distinguishable on the same simple object".

## Findings

- All 15 DNA blocks were the router template; the tools differed only by tag words ("Graphite texture", "Smudged texture", "Line shading"), so nothing kept graphite, charcoal and pen apart.
- Brand names in names or DNA: Marker (Copic), "Prismacolor drawing".
- Three names duplicate pack_04 presets: Ballpoint Pen (SP04-072), Colored Pencil (SP04-022), Scratchboard (SP04-023).
- Cards: several tools look like something else. Soft Pastel reads as an oil landscape, Technical Pen is a sketchy runner (not drafting), Continuous Line is many separate lines, Chalk Dust reads as graphite on grey, Marker apples look like watercolor.
- Tropes and repeats: cyclist with bike (Graphite), bearded bike mechanic (Scratchboard), bearded guitarist (Oil Pastel), tram (Conte), generic brunette gardener (Ballpoint), hiker with dog (Continuous Line), lantern alley (Silhouette); kite, pear-in-hand and apple bowl repeat subjects from Traditional Painting.

## Changes

- DNA rewritten for all 15 (version 2). The shared `subject_treatment` states the review rule: the tool must be identifiable by line quality, pressure response and paper behavior even on a simple object. Graphite has a silvery sheen and no true black, charcoal has velvet matte blacks with eraser lifts, and pen builds every value from swelling-nib hatching. Graphite, Charcoal and Pen each have one simple-object brief (iron key, crow skull, snail shell).
- Renamed 4 (aliases in spec): Ballpoint Pen → Ballpoint Scribble Shading (circular scribble tone, distinct from SP04-072's micro-hatching), Colored Pencil → Burnished Colored Pencil, Marker (Copic) → Alcohol Marker Rendering (brand), Scratchboard → Clayboard Scratch Drawing.
- `dropAvoid` `noise`/`blurry` on Charcoal, Soft Pastel and Chalk Dust (dust and smudge are the medium).
- 3 new briefs per preset (60), no repeated subject; Technical Pen briefs forbid labels and dimensions; Silhouette forces profile poses.
- New presets (pending cards): Blind Contour Drawing, Reed Pen Drawing, Graphite Powder Lift-Out, Watercolor Pencil Dissolve, Carpenter Pencil Block Sketch. Category now 20. Skipped because they already exist: Stipple (Dotwork), Brush Pen Ink, Fountain Pen, Loose Gesture Energy Sketch, Silverpoint on Toned Ground, White Chalk on Dark Stock, Directional Wax Pencil, Sanguine Iron Gall Study.
