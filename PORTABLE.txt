Cozy Studio portable start
===========================

Each portable ZIP is built for one operating system and CPU architecture:
windows-x64, windows-arm64, linux-x64, linux-arm64, macos-x64 or
macos-arm64. macos-arm64 is for Apple Silicon; macos-x64 is for Intel Macs.
Linux needs glibc 2.28 or newer, Bash and a browser (not musl/Alpine).
macOS needs macOS 13 or newer.

The ZIP includes its own Bun runtime, so no global Bun install is needed.
Extract the ZIP before you start it.

Windows: open scripts/Cozy Studio.bat.
macOS: open scripts/Cozy Studio.command. If needed, run:
  chmod +x "scripts/Cozy Studio.command"
Linux: open scripts/Cozy Studio.sh or run:
  bash "scripts/Cozy Studio.sh"
If an extractor drops Unix executable permissions, run:
  chmod +x runtime/bun scripts/portable-launch.sh scripts/Cozy\ Studio.*

The launcher locates the app from its own path, starts one local-server process
and opens a browser. If automatic browser opening fails, open the printed URL.
Codex CLI is not required to open the app or connect ChatGPT. The launcher
does not bundle ChatGPT login. Sign in from Studio after it opens.

If STUDIO_LIBRARY_DIR is unset, these wrappers use "Cozy Studio Library"
inside the app folder, beside scripts/. An explicit Library path is preserved.
Generated images still use the configured images destination.

See docs/PLATFORMS.md for paths, permissions and what to include in an
error report.
